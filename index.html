WhatsApp Contact List Manager

Clean, format and de-duplicate phone numbers. Everything stays on your device.

Format check only. A number marked "valid format" looks like a real phone number. It does not mean the number is registered on WhatsApp. This tool never contacts WhatsApp or any server.
Private by design: numbers are processed in this browser tab and never uploaded, sent or saved. Closing or clearing the page erases them.

Generate numbers (format only)

Creates numbers that match a dialing-plan format you specify. It does not check whether a number is real, assigned to anyone, or on WhatsApp.

These are commonly published examples of blocks Ofcom originally allocated to each network — not a live lookup. Ofcom reassigns blocks, numbers get ported between networks, and MVNOs (giffgaff, Tesco Mobile, etc.) borrow ranges from these four, so treat this as a rough starting point and edit the prefixes below if you need accuracy.

Each line is a full prefix: country code plus whatever digits you want fixed. E.g. for +44, enter 4479 for all 079xx numbers, or go further and type 447911 to fix the next digits too — only the digits after your prefix are randomly filled.
